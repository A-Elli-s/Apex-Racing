# Apex Racing World — Development Preview

This `dev` branch is the staging area for website changes. Review changes on the Cloudflare Pages branch preview before opening a pull request into `main`. The `main` branch remains the public production website.

Workflow: commit changes to `dev` → check Cloudflare preview → open a pull request from `dev` into `main` → review and merge when ready.

Do not put secrets, tokens, or private email addresses in this repository. Cloudflare Pages production and preview environment variables are separate.
